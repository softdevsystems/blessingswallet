Data Safety

Intended disclosure for the local-first release of Blessings Wallet.

Important: This page assumes the final Android release has no ads, no online account, no cloud sync, no analytics or remote crash-reporting SDK, and does not transmit blessing, tithe, offering, or custom-fund records off the device. If the implementation changes, update this page and the Google Play Data Safety form.

Notification Permission

If the user enables reminders, Blessings Wallet may request Android notification permission. Reminder settings consist of an enabled/disabled state, a selected day, and a selected time. This is intended to support local reminders only.

Sharing

The Share this App feature is intended to share information about Blessings Wallet or its store listing. It should not automatically include the user's stewardship records.

Voluntary Support

If the app displays GCash or another external method for voluntary developer support, the payment is handled outside Blessings Wallet. The app should not request or store the user's GCash PIN, password, authentication code, or wallet balance. Voluntary support should not unlock digital features or benefits.

Data Deletion

Users may delete individual local records, use Delete All Data if available, clear app storage through Android settings, or uninstall the app. Because no online account is required, there is no Blessings Wallet server account to delete.

Pre-Publication Check

  • No advertising SDK is included.
  • No Firebase Analytics or similar analytics SDK is included.
  • No Firebase Crashlytics or similar remote crash-reporting SDK is included.
  • No cloud database or sync service is included.
  • No account/login system is included.
  • No advertising ID is collected.
  • No location, contacts, SMS, call-log, microphone, or unnecessary camera permission is requested.
  • Notification permission is used only for reminders.
  • Delete All Data is available if represented in the app or policy.
  • The Privacy Policy and Google Play Data Safety answers match the final signed AAB/APK.
